# Placeholder examples

`linked-placeholder-records.json` is intentionally synthetic. It demonstrates the v0.6 chain:

`Dataset → DatasetVersion → ReferenceSpace → SpatialTransformation → SpatialRepresentation → Observation → Claim / EvidenceRecord`

It also shows `BrainRegion → AtlasMapping → Atlas` and a relationship classified as `model-derived`.

The generic `atlas` example object is included only to make cross-record links legible; an Atlas schema can be added when the project formalizes atlas metadata requirements.
