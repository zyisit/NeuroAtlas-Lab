# Data Sources

Potential foundational sources include:

- EBRAINS / Julich Brain Atlas
- Allen Institute brain resources
- Human Connectome Project
- OpenNeuro
- NeuroMorpho.Org
- ChEBI
- Gene Ontology
- IUPHAR/BPS Guide to PHARMACOLOGY

Before ingesting any source, record:

- source identity
- version
- retrieval date
- license
- attribution requirements
- relevant identifiers
- transformations performed
