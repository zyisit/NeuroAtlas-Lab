# Architecture

The planned platform separates five major concerns:

1. Presentation — React and educational UI
2. Visualization — Three.js/WebGL and spatial assets
3. Domain knowledge — anatomy, connectivity, cellular, molecular, and functional entities
4. Computational models — equations, parameters, interventions, simulations
5. Evidence/provenance — sources, claims, datasets, licenses, and transformations

The frontend must not become the scientific data model.

See `docs/ontology/` and `schemas/` for the current formal data contract.
