# Examples

`hippocampus-bundle.json` is a **synthetic placeholder** bundle. It uses real
region names and real UBERON identifiers so the shape looks like production
data, but every source, dataset, coordinate, and value is a placeholder and
every claim is deliberately `uncertain` / `draft`.

It exercises all 15 record types and every reference field the validator checks.
Copy it as a template; do not cite it.
